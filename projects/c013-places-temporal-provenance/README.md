# C013 PLACES Temporal Provenance

Stage 0 foundation for the frozen C013 controlled-execution protocol. This directory is not a manuscript workspace. Current Stage 0A artifacts preserve dataset anchors, retrieval evidence, validation schemas, a preliminary sentinel-measure crosswalk, tests, and an explicit discrepancy log.

The `data/raw/metadata/*.official-metadata-extract.json` files are **browser-mediated extracted official metadata snapshots**, not raw HTTP payloads. The committed acquisition script is the required path to byte-identical raw snapshots in a network-enabled clean room.
